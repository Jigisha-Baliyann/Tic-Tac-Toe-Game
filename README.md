
# 🎮 Tic-Tac-Toe Game  

A simple **Tic-Tac-Toe** game built with **HTML, CSS, and JavaScript**. This project provides an interactive UI to play against another player.  

## 🚀 Features  
✔️ Two-player mode  
✔️ Responsive design  
✔️ Interactive UI with animations  
✔️ Winner announcement & restart functionality  

## 🛠️ Tech Stack  
- HTML  
- CSS  
- JavaScript
